# Configuration - Users, Groups and Login Providers

Manage identities and permissions under **Console > Configuration**:

- [Users](User-Management.md) controls individual accounts, realm access,
  graph permissions, and account settings.
- [User Groups](User-Group-Management.md) assigns shared permissions to users.
- [Login Providers](Login-Providers.md) configures external authentication on
  the unreleased Cacti 1.3 development branch.

Authentication proves an identity; Cacti's user and group permissions determine
what that identity can see and change. Review both when provisioning accounts.

In Cacti 1.2, external directory domains are configured through
[User Domains](User-Domains.md). See [Authentication](Settings-Auth.md) for the
version-specific options.

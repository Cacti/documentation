# Установка и обслуживание Cacti в Linux и FreeBSD

Это новое руководство для замены архивных инструкций по UNIX. Оно относится
к ветке `develop` Cacti 1.3, которая ещё не выпущена. Для Cacti 1.2 используйте
[руководство ветки 1.2.x][stable]. Русский вводный раздел написан заново;
приложение содержит полные актуальные инструкции на английском языке.
Это не полный перевод всего руководства Cacti.

## Подготовка

Проверьте [требования][requirements] выбранной версии. Используйте ОС с
действующими обновлениями безопасности и совместимые PHP, СУБД и RRDtool.
Для Linux выберите [Ubuntu/Debian][debian] либо [Enterprise Linux][linux].
Для FreeBSD прочтите раздел о пакетах, вариантах PHP и путях в
[общей инструкции][install]. Не применяйте команды `systemctl` в FreeBSD.
Пакет Cacti 1.2 не является сборкой Cacti 1.3.

Перед изменениями сохраните базу данных, RRD-файлы и конфигурацию. Проверьте
восстановление копии. Установите зависимости по инструкции выбранной платформы.
Для исходного кода выполните от имени владельца приложения:

```sh
composer install --no-dev
composer check-platform-reqs --no-dev
php --ini
php -m
```

Не обходите ошибки проверки платформы. Настройки и расширения PHP CLI и веб-PHP
проверяются отдельно. Загрузите `cacti.sql` только в новую базу данных.
Не импортируйте этот файл поверх существующей установки.

## Настройка и запуск

Укажите параметры подключения в `include/config.php`. Ограничьте доступ к
паролю базы данных и запретите веб-серверу изменять код приложения. Отдельной
учётной записи poller нужны права записи только в рабочие каталоги.
Не запускайте сбор данных от имени администратора без необходимости.

Настройте HTTPS и ограничьте доступ к установщику. Пройдите проверки базы
данных, часового пояса, PHP и разрешений в веб-интерфейсе. Измените начальный
пароль. Настройте ровно одно расписание с абсолютными путями к PHP и
`poller.php`. Не запускайте второй poller одновременно. При использовании
[Spine][spine] проверьте совместимость его версии с Cacti.

## Проверка сбора данных

В **Console > Devices** добавьте устройство с подходящим шаблоном. Укажите
версию SNMP и реквизиты, разрешённые на устройстве. Ограничьте доступ SNMP
адресом сборщика. Создайте графики и добавьте их в дерево. Подождите несколько
интервалов опроса. Подробные действия приведены в [инструкции по
графикам][graphs].

![График с историческими примерными данными](../../images/graphs-edit.png)

На снимке показаны исторические данные и прежняя версия интерфейса.

## Диагностика и обновление

Сначала проверьте службы, системное время, пути программ, настройки PHP и
права доступа. Изучите журнал Cacti. Для одной проблемной метрики используйте
[диагностику источника данных][debug]. Подробное журналирование включайте
временно и только там, где оно требуется. Не удаляйте RRD-файлы и не создавайте
базу заново из-за пустого графика.

Перед обновлением прочтите примечания к выпуску и [порядок
обновления][upgrade].
Сохраните внешние каталоги данных, плагины и расписания. Сначала проверьте
обновление в тестовой среде. Выполните обновление базы только один раз.
Завершите [настройку безопасности][hardening] до открытия доступа
пользователям.

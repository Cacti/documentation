# Установка Cacti в Windows

Это новое руководство заменяет архивные инструкции Windows. Оно описывает
состояние ветки `develop` Cacti 1.3, а не выпущенную версию. Для установленной
Cacti 1.2 используйте [документацию 1.2.x][stable]. Русский вводный раздел
дополнен полной актуальной английской инструкцией Windows; это не полный
перевод всего руководства.

## Сначала проверьте совместимость

В текущей ветке разработки Composer безусловно требует `ext-pcntl` и
`ext-posix`. Нативная PHP для Windows не предоставляет эти расширения.
Поэтому установка зависимостей текущего исходного кода на нативной Windows
блокируется. Не обходите проверки платформы и не редактируйте сгенерированные
файлы Composer. Выберите совместимый выпуск либо поддерживаемую UNIX-систему.
Готовая сборка также должна пройти проверку платформы при запуске.

Остальные шаги применимы только к совместимой сборке. Проверьте
[требования][requirements] и [полную инструкцию Windows][windows] для своей
версии. Используйте обновляемую Windows Server, совместимые PHP, СУБД и
RRDtool.
Поддержка ОС сама по себе не подтверждает совместимость сборки Cacti.

## Подготовьте службы и учётные записи

Выберите IIS с FastCGI либо совместимую сборку Apache. Для IIS обычно требуется
PHP Non-Thread-Safe; для модуля Apache нужна совместимая Thread-Safe сборка.
В IIS обработчик FastCGI использует `php-cgi.exe`, а не `php.exe`.
Настройте HTTPS и ограничьте доступ на время установки.

Используйте отдельные учётные записи веб-сервера и задания сбора данных.
Дайте им чтение кода, конфигурации и исполняемых файлов. Разрешите запись
только в необходимые рабочие каталоги. Не разрешайте изменять системные
исполняемые файлы Windows. Установите библиотеки PHP по инструкции поставщика;
не копируйте DLL в системные каталоги Windows.

Проверьте конфигурацию PHP CLI и веб-сервера отдельно. Для примера с PHP в
`C:\php` выполните:

```console
C:\php\php.exe --ini
C:\php\php.exe -m
```

Укажите реальные пути и параметры базы в `include/config.php`. Импортируйте
`cacti.sql` только для новой установки. Не заменяйте им существующую базу.
Сохраните исходную базу, конфигурацию и RRD-файлы перед любым обновлением.

## Завершите установку и проверьте результат

Пройдите проверки веб-установщика и измените начальный пароль. В Планировщике
заданий Windows создайте одно задание от отдельной учётной записи с абсолютными
путями к PHP и `poller.php`. Задайте рабочий каталог и запретите запуск второго
экземпляра, пока предыдущий работает. Используйте интервал своей установки.

Добавьте устройство в **Console > Devices**, проверьте SNMP и создайте графики
по [инструкции][graphs]. Подождите несколько интервалов сбора.

![График с историческими примерными данными](../../images/graphs-edit.png)

Снимок показывает исторические данные и старый интерфейс, а не подтверждение
работы текущей ветки на Windows.

При проблемах проверьте журнал задания, его учётную запись, рабочий каталог,
права доступа и конфигурацию PHP. Затем используйте [диагностику][debug].
Перед обновлением следуйте [инструкции Windows][windows-upgrade], проверьте
восстановление резервной копии и совместимость плагинов. Не запускайте два
сборщика одновременно во время проверки или обновления.
